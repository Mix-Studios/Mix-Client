01

CHECK THE HASH

Compare the SHA-256 shown on the verify section with the file you got. On Windows run certutil -hashfile <file> SHA256; on macOS or Linux, shasum -a 256 <file>.

02

RUN IT

Double-click the jar, or from the folder you saved it in run java -jar MixClient-0.0.0-all.jar.

03

SIGN IN AND PLAY

The client opens its own window and asks for your Microsoft account there — the sign-in never happens in the browser and no token is ever pasted anywhere.

NOTES

Unsigned build. Windows SmartScreen asks for “More info → Run anyway”. macOS blocks the first launch of an unsigned app: right-click MixClient in Applications and choose Open, or run xattr -dr com.apple.quarantine /Applications/MixClient.app. Linux has no prompt; install the .deb or .rpm with your package tool, or run the AppImage.

The jar runs anywhere. Every other file bundles its own Java runtime; the plain jar needs Java 17 or newer.
