STEPS

01

CHECK THE HASH

Compare the SHA-256 shown on the verify section with the file you got. On Windows run certutil -hashfile <file> SHA256; on macOS or Linux, shasum -a 256 <file>.

02

RUN IT

Double-click the jar, or from the folder you saved it in run java -jar MixClient-1.0.0-all.jar.

03

SIGN IN AND PLAY

The client opens its own window and asks for your Microsoft account there — the sign-in never happens in the browser and no token is ever pasted anywhere.

NOTES

Unsigned build. Windows SmartScreen asks for “More info → Run anyway”, and macOS Gatekeeper may need a right-click → Open the first time. The jar needs Java 17 or newer.

Installer in progress. A packaged .exe installer for Windows is coming soon; until it ships, the jar is the download for every platform.
